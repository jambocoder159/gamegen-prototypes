# Audio notes

All audio in `public/common/audio/` is **original procedural synthesis** generated by
`/workspace/gamegen-games/_tools/audio_gen.py`. There are no third-party samples and
no licence obligations. The clips are placeholders **awaiting a human ear-selection
pass** before release.

| file | where it is used |
|---|---|
| `bgm_base.mp3` | Looping background music; starts after the title "enter" gesture, pauses when the tab is hidden, stops on mute. |
| `sfx_hover.mp3` | Pointer-enter on every button. |
| `sfx_click.mp3` | Press on every button. |
| `sfx_add.mp3` | Adding/removing a topping, and clearing the bowl. |
| `sfx_serve.mp3` | Pressing Serve. |
| `sfx_ok.mp3` | Correct order served. |
| `sfx_wrong.mp3` | Wrong order served, and when a customer leaves angry. |
| `sfx_over.mp3` | Game over. |

No sound effects play during the title demo; only BGM plays, and only after the user
gesture that creates/resumes the AudioContext. Buffers are decoded once during the
preload gate and reused for playback.
