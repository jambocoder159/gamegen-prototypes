# Audio notes

All audio in this game is **original procedural synthesis** generated by
`/workspace/gamegen-games/_tools/audio_gen.py`. There are no third-party samples
and no licence obligations. The files are placeholders awaiting human-ear
selection/retuning before any public release.

Files live in `public/common/audio/` and are referenced from
`src/config/assets.ts`.

| file | used for |
|---|---|
| `bgm_base.mp3` | Looping background music. Starts after the "Enter game" gesture; never during the title demo's game events. Pauses when the tab is hidden; stops when muted. |
| `sfx_move.mp3` | A move that slid tiles **without** any merge. |
| `sfx_merge.mp3` | A move where at least one merge happened (one play per move). |
| `sfx_win.mp3` | First time a Dragon mochi (tier 9) is formed. |
| `sfx_over.mp3` | Game over (no moves left). |
| `sfx_click.mp3` | Pressing any button. |
| `sfx_hover.mp3` | Pointer entering any button. |

## Removed

`sfx_spawn.mp3` was **deleted**. Tile spawns are intentionally silent (per
PLAN / brief), so keeping the file would violate the zero-residue rule. It has
no references in code or the asset table.
