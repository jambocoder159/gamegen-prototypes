# Lantern Rise（升燈）— PLAN.md

> 標記：[事實]／[策略推論]／[待驗證假設]。不含未經查證的市場數字。

## 1. 一句話
按住讓天燈上升、放開下沉，在烏鴉與雷雨雲之間穿行，吃星火補充燈油，飛得越遠越高分。

## 2. 目標客群 / 平台
- 客群 [策略推論]：動態牆上想玩「一根手指、3 分鐘內有成就感」的玩家，偏好氛圍好看的反應類遊戲。
- 發布 [事實]：HTML ZIP 上傳 GameGen（社群分享用），React 19 + TS + Vite。
- 差異化 [待驗證假設]：按住上升類操作成熟；差異在「燈油」資源管理（上升耗油、星火/火滴補油）與紙雕美術。

## 3. 核心循環
按住(螢幕任意處／空白鍵／↑)上升，放開受重力下沉 → 避開烏鴉(橫飛、正弦)與雷雨雲(靜止障礙)，碰到＝損失護盤/結束 → 吃星火(+分數、+少量燈油)與火滴(+大量燈油) → 上升時消耗燈油，油盡則只能下沉 → 落地或被撞＝結束 → 結算顯示距離、星數、最高紀錄。
- 難度隨距離上升：速度、障礙密度逐步提高，上限固定（可用 headless 模擬調整）。
- 生成規則確保一定有可通過路徑（沿路擺星火帶路，玩家看星火走向預判高度）。
- 操作跟手：按住/放開即時反應，不飄；一次碰撞 = 一次傷害，撞後短暫無敵、不連撞。

## 4. 版面
- 直式：資訊（距離、星火數）在上方，燈油條在左側或上方，全螢幕觸控（左右半邊皆可觸發）。
- 橫式／近方形：同一套 HUD，靠邊排列。
- 標題：背後由電腦自己飛（AI 控制天燈避障），logo 在上、進入鍵在下。

## 8. 實作定案數值（在 `src/game/logic.ts` 的 CONFIG 微調）
以建議值為基礎，用 headless 模擬（`scripts/sim.mjs`）微調後定案，與建議值的差異如下：
- 重力 520、推力 950、vy 夾在 [-250, 340]：維持建議值。
- 每局先顯示 3–2–1 倒數；倒數中物理、障礙、距離與燈油全部暫停，不能受傷。減少動態效果時仍以靜態文字讀秒。
- 燈油 100，按住上升每秒耗 **6**（原 15，降低 60%）；不按不耗油。星火 +9 油/+10 分、火滴 +35 油、撞擊 -35 油。
- 無補給且無撞擊、持續按住時，油量曲線為 `max(0, 100 - 6t)`（t 不含倒數）；固定 120Hz 實測 16.675 秒耗盡，18.342 秒落地，加倒數為 21.342 秒。平飛平均推力比約 520/950 = 54.7%，無補給可維持約 30.45 秒。星火仍可維持長程飛行。
- 低於 25%：油條脈動顏色、警告符號與四語文字、aria-live 公告、一次音效（重用 sfx_hit，遵守靜音）；補油回到門檻以上後可再次提示。減少動態效果時取消脈動。油條實際填充高約 20.2px，附燈油標籤與百分比。
- 天花板依 HUD 實測底邊 +12px 計算（safe-area 一併計入，上限世界 y=310），燈體上邊保持在 HUD 下方；地面線 y=594 碰到即結束。
- 星火／火滴中心曲線改為 `295 + 65 sin(2πx/1150+p1) + 24 sin(2πx/460+p2)`，夾在 `[HUD天花板+70, 410]`。變更視窗時更新已生成補給的位置，維持可到達、避開 HUD，且不沉到下方。
- 撞擊 -35 油、向下擊退、1.4 秒無敵（不連撞）；世界速度 150→320，約 180 秒達上限；障礙密度同步漸增。
- 新調校結果（20 個種子、每局上限 240 秒，不含倒數）：150ms 反應機器人三版面平均 225–232 秒；三版面完美操作皆 20/20 達 240 秒；難度上限起跑亦 20/20 通過 180 秒。獨立邏輯測試另驗證 6 種視窗 ×8 種子，48/48 完美操作達 240 秒，並抽樣 233,568 個補給高度。這是無終點的分數遊戲，目標是延長可玩續航。
- 首局下方三步教學：按住→放開→星火補給，操作自動推進；可略過、30 秒內收起，? 可重開。四語；localStorage 記錄完成／略過。
- 每秒與 pagehide／隱藏分頁保存版本化進度，包含 RNG、實體、油量與倒數；標題可繼續（先暫停）或新遊戲。資料逐欄驗證、限制大小，異常安全重設；結束或重開清除舊局。
- HUD 標籤至少 18px、關鍵數字 20px、圖示按鈕 48×48px、星火圖示 28px。油條統一水平置頂；標題文字與美術保持分離，短橫畫面採雙欄。
