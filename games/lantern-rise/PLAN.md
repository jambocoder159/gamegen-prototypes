# Lantern Rise（升燈）— PLAN.md

> 標記：[事實]／[策略推論]／[待驗證假設]。不含未經查證的市場數字。

## 1. 一句話
按住讓天燈上升、放開下沉，在烏鴉與雷雨雲之間穿行，吃星火補充燈油，飛得越遠越高分。

## 2. 目標客群 / 平台
- 客群 [策略推論]：動態牆上想玩「一根手指、3 分鐘內有成就感」的玩家，偏好氛圍好看的反應類遊戲。
- 發布 [事實]：HTML ZIP 上傳 GameGen（社群分享用），React 19 + TS + Vite。
- 差異化 [待驗證假設]：按住上升類操作成熟；差異在「燈油」資源管理（上升耗油、星火/火滴補油）與紙雕美術。

## 3. 核心循環
按住(螢幕任意處／空白鍵／↑)上升，放開受重力下沉 → 避開烏鴉(橫飛、正弦)與雷雨雲(靜止障礙)，碰到＝損失護盤/結束 → 吃星火(+分數、+少量燈油)與火滴(+大量燈油) → 上升時消耗燈油，油盡則只能下沉 → 落地或被撞＝結束 → 結算顯示距離、星數、最高紀錄。
- 難度隨距離上升：速度、障礙密度逐步提高，上限固定（可用 headless 模擬調整）。
- 生成規則確保一定有可通過路徑（沿路擺星火帶路，玩家看星火走向預判高度）。
- 操作跟手：按住/放開即時反應，不飄；一次碰撞 = 一次傷害，撞後短暫無敵、不連撞。

## 4. 版面
- 直式：資訊（距離、星火數）在上方，燈油條在左側或上方，全螢幕觸控（左右半邊皆可觸發）。

- 標題：背後由電腦自己飛（AI 控制天燈避障），logo 在上、進入鍵在下。

## 8. 實作定案數值（在 `src/game/logic.ts` 微調）
以建議值為基礎，用 headless 模擬（`scripts/sim.mjs`）微調後定案，與建議值的差異如下：
- 重力 520、推力 950、vy 夾在 [-250, 340]：維持建議值。
- 燈油 100，上升每秒耗 15（建議 16，略降讓續航更穩）；星火 +9 油/+10 分（建議 +8 油）、火滴 +35 油。
- 天花板軟夾在 y=78（原 48 下移，避免天燈升到頂時蓋住上方 HUD）；地面線 y=594 碰到即結束。
- 撞擊 -35 油、向下擊退、1.4 秒無敵（不連撞）；世界速度 150→320，約 180 秒達上限；障礙密度同步漸增。
- 調校結果：150ms 反應機器人平均約 70 秒（目標 40–90），完美操作可過 3 分鐘（含難度上限），皆 60/60 通過。
