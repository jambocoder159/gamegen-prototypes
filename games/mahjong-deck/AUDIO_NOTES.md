# Audio notes

All audio in Mahjong Deck is **original procedural synthesis** generated by
`/workspace/gamegen-games/_tools/audio_gen.py`. There are no third-party samples
and no licence obligations. These are **placeholders pending human-ear review and
selection** — timbre, loudness balance and length should be tuned (or replaced
with hand-picked synthesis) before release.

Files live in `public/common/audio/` and are preloaded and decoded into WebAudio
buffers during the loading gate; every later playback reuses those buffers. A
file that fails to load simply stays silent (the game never breaks). Audio is
muted during the title demo, respects the persisted mute toggle, and pauses when
the tab is hidden.

| File | Where it is used |
|---|---|
| `bgm_base.mp3` | Looping background music; starts after the "Enter game" gesture |
| `sfx_select.mp3` | Selecting a tile (and deselecting) |
| `sfx_match.mp3` | A matched pair is cleared |
| `sfx_wrong.mp3` | Mismatch (wrong pair) — also the auto-reshuffle-for-a-heart cue |
| `sfx_card.mp3` | Playing a hand card, choosing a reward card, or a Shuffle-card reshuffle |
| `sfx_clear.mp3` | A stage is cleared |
| `sfx_win.mp3` | Victory (all five stacks cleared) |
| `sfx_lose.mp3` | Defeat (out of hearts) |
| `sfx_click.mp3` | Pressing any button (`sfx_click`) |
| `sfx_hover.mp3` | Pointer entering any button (`sfx_hover`) |

Sound effects are never played during the self-running title demo.
