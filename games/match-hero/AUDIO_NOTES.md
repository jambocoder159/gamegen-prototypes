# Audio notes · Match Hero Tower

All audio in `public/common/audio/` is original procedural synthesis generated by `/workspace/gamegen-games/_tools/audio_gen.py`, with no third-party samples or licence obligations. It awaits human listening review for levels, EQ and final selection.

| File | Event |
|---|---|
| `bgm_base.mp3` | Loop after Play/Continue unlocks WebAudio. |
| `sfx_hover.mp3` | Pointer enters a button. |
| `sfx_click.mp3` | Button press. |
| `sfx_swap.mp3` | Gem swap begins. |
| `sfx_invalid.mp3` | Invalid swap returns. |
| `sfx_match.mp3` | First gem clear, including star blasts. |
| `sfx_combo.mp3` | Subsequent cascade clears. |
| `sfx_hit.mp3` | Normal automatic attack. |
| `sfx_crit.mp3` | Critical automatic attack. |
| `sfx_hurt.mp3` | Enemy damages the hero. |
| `sfx_kill.mp3` | Enemy defeated. |
| `sfx_coin.mp3` | Kill gold or successful upgrade purchase. |
| `sfx_skill.mp3` | Fireball. |
| `sfx_heal.mp3` | Heal. |
| `sfx_haste.mp3` | Haste. |
| `sfx_boss.mp3` | Enter a boss floor. |
| `sfx_floor.mp3` | Enter the next ordinary floor. |
| `sfx_defeat.mp3` | Retreat. |

Music and effects reuse preloaded decoded buffers. Sound choice persists. The audio context suspends while the tab is hidden. The automatic title adventure has no combat effects; the single Play/Continue gesture unlocks audio and starts music.
