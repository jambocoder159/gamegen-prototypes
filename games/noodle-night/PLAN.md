# Noodle Night（夜市麵攤）— PLAN.md

> 標記：[事實]／[策略推論]／[待驗證假設]。不含未經查證的市場數字。

## 1. 一句話
客人頭上冒出訂單泡泡，點配料做出一碗對的麵再按鈴上餐，連續上對有連擊加成，客人等太久或上錯三次就打烊。

## 2. 目標客群 / 平台
- 客群 [策略推論]：喜歡輕度時間管理、可愛動物角色與美食主題的休閒玩家，單手點選即可玩。
- 發布 [事實]：HTML ZIP 上傳 GameGen（社群分享用），React 19 + TS + Vite。
- 差異化 [待驗證假設]：時間管理／點餐題材成熟；差異在「4 位客人 × 3 表情」的反應回饋與夜市氛圍。

## 3. 核心循環
客人入座（耐心條開始遞減）→ 訂單泡泡顯示 1–4 個配料圖示 → 玩家點配料鈕把配料放進碗（點碗可清空）→ 按「上餐」鈴 → 正確：客人開心、得金幣＋連擊、耐心剩餘越多獎勵越高；錯誤：客人生氣、扣 1 顆愛心、連擊歸零 → 耐心歸零：客人氣走、扣愛心 → 愛心歸零結算。
- 難度隨進度：配料數 1→4、耐心時間縮短（有下限）、同時 1→2 位客人（2 位時點客人選擇要服務誰）。
- 6 種配料（蛋、蔥、叉燒、魚板、辣椒、青江菜）；訂單以配料「集合」比對，不要求順序。
- 最高分存 localStorage。

## 4. 版面
- 直式：上方愛心／金幣／連擊，中間客人與泡泡、廚師動畫，下方碗＋6 顆配料鈕＋上餐鈴（拇指區）。
- 橫式／近方形：客人置中，配料鈕在左右兩側排列，上餐鈴在右側（不在正中線）。
- 標題：背後由電腦自己經營麵攤（AI 依訂單點配料並上餐），logo 在上、進入鍵在下。
