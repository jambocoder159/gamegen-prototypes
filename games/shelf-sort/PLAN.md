# Shelf Sort（貨架理貨）— PLAN.md

> 標記：[事實]＝來自 skill／已驗證；[策略推論]＝企劃判斷；[待驗證假設]＝需上線數據或 Jambo 決定。不含任何市場數字。

## 1. 一句話
把亂七八糟擺在貨櫃倉庫貨架上的商品，一件件搬到空位，讓每一層貨架擺滿 3 件相同商品，全部理好就過關。

## 2. 目標客群 / 平台
- 客群 [策略推論]：喜歡「整理、分類」療癒感與短關卡益智的休閒手機玩家；單手直拿，一關 30 秒–2 分鐘。
- 平台 [事實，依 skill 預設]：HTML ZIP（GameGen），React 19 + TypeScript + Vite，noskin 架構。
- 差異化 [待驗證假設]：「分類整理」是成熟玩法；差異在貨櫃倉庫主題、店員貓吉祥物、無限復原、確定可解的關卡。需上線後留存／分享數據驗證。

## 3. 核心循環
點一件商品（抬起）→ 點任一空位（可在同層或別層）放下 → 某層 3 件相同 → 清除（閃光＋店員歡呼）→ 全部清除過關 → 星等（依步數對比解答步數）→ 下一關。
- 規則：每層 3 格。關卡有 K 種商品各 3 件，S 層貨架（S>K，空位 = 3(S−K)）。
- 關卡 [實作決定]：共 12 關，可由種子產生、必經求解器驗證可解（`src/game/logic.ts`，UI／標題 AI／無頭測試共用）。K 由 3 增至 8、S=K+1 或 K+2 漸增難度。
- 星等 [實作決定]：第 2–4 關以精確最短解設定容錯，3 星 ≤ 最短解+1、2 星 ≤ 最短解+4，其餘 1 星。其他關卡保留貪婪解步數 / ceil(×1.5) 的門檻。
  | 關卡 | 精確最短步數 | 3 星上限 | 2 星上限 | 舊貪婪解步數 |
  |---|---|---|---|---|
  | 2 | 5 | 6 | 9 | 7 |
  | 3 | 7 | 8 | 11 | 7 |
  | 4 | 5 | 6 | 9 | 5 |
  `scripts/optimal-solver.mjs` 以 IDA*、貨架/格位對稱去重及各商品 3−最大同層數量的可採納下界，窮舉證明更短解不存在；`npm run test:logic` 驗證最短解可玩到過關及所有星等邊界。第 2 關收緊原本 7 步的 3 星預算；第 3、4 關依修正需求保留最短解+1 的明確容錯，原本貪婪解恰為最短解，不能聲稱這兩關比原先更緊。
- 功能：無限復原、重開、關卡選擇（已解鎖者）、音效開關、語言。
- 進度（已解鎖關卡、各關最佳星數）存 localStorage（白名單驗證）。
- 進行中關卡以 version=1 的合法移動序列保存（最多 5,000 步、200 KB）；重新載入後可選繼續或新遊戲。重播逐欄驗證恢復盤面、選取及復原記錄；壞資料安全清除。每步、復原、選取及 pagehide/visibilitychange 存檔；過關／重開／新遊戲清除。
- 初次遊玩顯示可略過的三步教學（拿起→放下→同層三件清除），隨操作前進，? 可重新開啟；位置與主要貨架/控制分開，四語皆支援。
- 已拿起商品時點佔用格：不改盤面、選取或步數，顯示搖動的 × 標記與格框、aria-live 短訊息及 35% 音量提示音。減少動態模式保留靜態標記。空格未選取時同樣提示。
- 預設語言依 navigator.languages 第一個支援語言，已儲存選擇優先；詳見 README。

## 4. 版面
- 直式（預設）：頂部關卡／步數 pill（panel_pill，標籤 18px、數字至少 22px），中間貨架直排（每層用 panel_shelf），底部按鈕列（復原、重開、選關、音效、語言）；店員貓在下方空處歡呼。
- 橫式 16:9 與近方形：貨架以 2 欄排列置中偏左，右側為資訊與按鈕直排；按鈕不在中線。
- 標題畫面：後方由求解器自動播放真實關卡（一步步搬商品）、logo 在上、「進入遊戲」＋語言在下；音訊未解鎖前靜音。

## 6. 合規檢查（對照 game-platform-standard §8）
- React 19 + TS；資產在 public/common/textures、audio；語系 public/config/language（en / zh-TW / zh-CN / ja，預設依瀏覽器／無匹配時 en）。
- 固定 relativePath 表；資源解析 style → commonPath → /common/ → /；單一資源失敗不白屏。
- 載入畫面＋真實進度＋「進入遊戲」手勢解鎖音訊。
- HTML ZIP 根目錄 index.html + poster.png；Asset Naming Rule V2。
- 品質：直式版面、摺疊機重排、prefers-reduced-motion、WCAG 2.2 AA 基本項（對比、鍵盤可操作［方向鍵移動焦點、Enter 選取］、焦點可見、aria-live、圖示按鈕≥48px、lang 屬性）。
- 無第三方 IP、無真錢、無追蹤。商品圖為通用圖案，無文字與品牌。
